🇧🇷 PORTUGUÊS (BRASIL)
────────────────────────────────────────────────────────
O WinCleam é uma ferramenta local de manutenção do Windows.
Os comandos só serão executados após sua seleção e confirmação.
Algumas operações exigem privilégios de administrador e podem
alterar arquivos do sistema, configurações de rede ou discos.
Antes de reparar discos com CHKDSK /f, faça backup dos dados.
O WinCleam não garante aumento de FPS nem melhoria de desempenho.
RAMMap e Process Lasso são aplicativos de terceiros e não estão
incluídos nesta instalação.
O código-fonte do WinCleam é distribuído sob a licença MIT.

ENGLISH (UNITED KINGDOM)
────────────────────────────────────────────────────────
WinCleam is a local Windows maintenance application.
System operations run only after you select and confirm them.
Some operations require administrator privileges and may change
system files, network settings or disk contents. Back up your data
before using CHKDSK /f to repair drives. WinCleam does not guarantee
better FPS or performance. RAMMap and Process Lasso are third-party
programmes and are not included in this installer.
WinCleam source code is distributed under the MIT Licence.
